Phase 2 · Where AI helped

Same evidence, written for a second reader.

The research was correct but read like a methods appendix. AI helped me translate it — every number stays exactly as the pipeline produced it.

FOR A STATISTICIAN

"Mean reciprocal rank of the true same-player×competition profile under cosine similarity over the full Wyscout feature set, with a combined-period z-score scaler."

FOR EVERYONE ELSE

"How high the same player's second-half profile appears when every eligible profile is ordered by fingerprint similarity to their first half."

What AI did
1Drafted a plain-language "What this means" for every metric card, which I reviewed against the methods. [CONFIRME]
2Reworked the landing page around a newcomer's first five minutes: question first, one example, then the caveats.
3[OUTRO USO REAL — ex.: revisão de acessibilidade, testes, refatoração do front-end]
What AI is never allowed to do
Recompute a value or invent a metric
Soften a caveat or make a recommendation
Mention a player or fact not in the evidence bundle

Any future AI narration is fail-closed: each factual sentence must cite evidence IDs, and invalid output falls back to deterministic text. No live LLM runs on any page today.
